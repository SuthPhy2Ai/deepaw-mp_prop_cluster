# MP 数据集样本与标签详细报告

**生成时间**: 2026-03-07
**数据源**: `data/db/mp_materials.db` (ASE SQLite Database)
**原始数据**: `data/raw/summary_all_merged.jsonl.gz` (280MB)
**总样本量**: **154,879** 条材料记录

---

## 执行摘要

本数据集包含从 Materials Project 下载的 154,879 个晶体材料的完整物理化学性质数据，用于多任务机器学习训练。数据覆盖热力学、电子结构、结构性质和弹性性质四大类共 18 个预测任务。

**关键发现**:
- ✅ 核心任务（能量、带隙、体积、密度）覆盖率 100%
- ⚠️ 弹性任务覆盖率较低（~8-31%），需要加权采样策略
- ⚠️ CBM/VBM 覆盖率 23-58%（仅非金属材料有效）
- ✅ 数据质量高，物理约束满足率 >94%
- 📊 数据分布：47% 金属，22% 稳定材料，48% 带隙为零

## 1. 任务定义与数据覆盖

### 1.1 多任务学习任务列表（18 个任务）

本项目训练多任务 GNN 模型预测以下 18 个材料性质：

#### **热力学任务组（3 个）**
| 任务名称 | 类型 | 单位 | 覆盖率 | 说明 |
|---------|------|------|--------|------|
| `energy_per_atom` | 回归 | eV/atom | 100% | 总能量（DFT 计算） |
| `formation_energy_per_atom` | 回归 | eV/atom | 100% | 形成能 |
| `energy_above_hull` | 回归 | eV/atom | 100% | 相对凸包能量（稳定性指标） |

#### **电子结构任务组（5 个）**
| 任务名称 | 类型 | 单位 | 覆盖率 | 说明 |
|---------|------|------|--------|------|
| `band_gap` | 回归 | eV | 100% | 带隙（PBE 泛函） |
| `cbm` | 回归 | eV | 23.2%* | 导带底能量 |
| `vbm` | 回归 | eV | 23.2%* | 价带顶能量 |
| `efermi` | 回归 | eV | 100% | 费米能级 |
| `is_metal` | 分类 | - | 100% | 金属性（47% 为金属） |

*注：CBM/VBM 仅对非金属材料有意义，实际覆盖率在非金属子集中为 ~58%

#### **稳定性任务组（1 个）**
| 任务名称 | 类型 | 单位 | 覆盖率 | 说明 |
|---------|------|------|--------|------|
| `is_stable` | 分类 | - | 100% | 热力学稳定性（22% 稳定） |

#### **结构性质任务组（2 个）**
| 任务名称 | 类型 | 单位 | 覆盖率 | 说明 |
|---------|------|------|--------|------|
| `volume` | 回归 | Ų | 100% | 晶胞体积 |
| `density` | 回归 | g/cm³ | 100% | 密度 |

#### **弹性性质任务组（4 个）**
| 任务名称 | 类型 | 单位 | 覆盖率 | 说明 |
|---------|------|------|--------|------|
| `bulk_modulus_vrh` | 回归 | GPa | 30.8% | 体积模量（VRH 平均） |
| `shear_modulus_vrh` | 回归 | GPa | 30.8% | 剪切模量（VRH 平均） |
| `homogeneous_poisson` | 回归 | - | 30.8% | 泊松比 |
| `universal_anisotropy` | 回归 | - | 30.8% | 各向异性指数 |

**注意**: 弹性任务覆盖率低（~8-31%），训练时需使用加权采样（`--oversample-elastic 4.0`）

### 1.2 训练阶段策略

#### **Stage A: 高覆盖任务（11 个任务）**
排除 `volume`, `density`, `is_stable`, 弹性任务（4 个）

**原因**:
- `volume`: 数值范围过大（5.6 - 20,090 Ų），导致梯度爆炸和 NaN loss
- `density`, `is_stable`: 为训练稳定性暂时排除
- 弹性任务: 覆盖率低，单独在 Stage B 处理

**Stage A 核心任务（8 个）**:
```
热力学: energy_per_atom, formation_energy_per_atom, energy_above_hull
电子: band_gap, cbm, vbm, efermi, is_metal
```

#### **Stage B/C: 全任务（18 个任务）**
包含所有任务，使用 `WeightedRandomSampler` 对弹性数据过采样（默认 4×）

## 7. 训练建议

### 7.1 Stage A 训练（推荐起点）

```bash
python scripts/train_multitask.py \
  --split data/splits/split_iid_seed42.json \
  --stage a \
  --backbone graph \
  --batch-size 64 \
  --num-workers 8 \
  --exclude-tasks volume density is_stable \
  --epochs 50
```

**关键参数**:
- `--exclude-tasks volume density is_stable`: **必须排除**，否则 NaN loss
- `--num-workers 8`: GPU 利用率从 0% 提升到 42%
- `--batch-size 64`: 平衡速度和内存

### 7.2 Stage B 训练（包含弹性任务）

```bash
python scripts/train_multitask.py \
  --split data/splits/split_iid_seed42.json \
  --stage b \
  --backbone graph \
  --batch-size 32 \
  --num-workers 8 \
  --oversample-elastic 4.0 \
  --epochs 50
```

**关键参数**:
- `--oversample-elastic 4.0`: 弹性数据过采样 4 倍（补偿 7% 覆盖率）
- `--batch-size 32`: 降低批量大小（弹性任务更复杂）

### 7.3 Enhanced Graph Backbone（Phase 2）

```bash
python scripts/train_multitask.py \
  --split data/splits/split_iid_seed42.json \
  --stage a \
  --backbone enhanced_graph \
  --cutoff 8.0 \
  --max-neighbors 48 \
  --n-rbf 128 \
  --use-angles \
  --use-edge-update \
  --lr 2e-4 \
  --epochs 50 \
  --exclude-tasks volume density is_stable
```

**改进**:
- 更大图覆盖范围（8.0Å vs 6.0Å）
- 三体相互作用（角度特征）
- 边更新机制
- AMP 兼容（修复 Phase 1 训练不稳定问题）

## 8. 已知问题与注意事项

### 8.1 数据问题

1. **Volume 任务**: 数值范围过大（5.6 - 20,090），导致梯度爆炸
   - **解决方案**: Stage A 必须排除 `--exclude-tasks volume`

2. **CBM/VBM 覆盖率**: 仅 23-58%（金属材料无 CBM/VBM）
   - **解决方案**: 训练时自动计算 mask，仅对有效样本计算损失

3. **弹性数据稀疏**: 仅 7-11% 样本有弹性数据
   - **解决方案**: Stage B 使用 `WeightedRandomSampler` 过采样

### 8.2 训练问题

1. **GPU 利用率低**: 不设置 `num_workers` 时 GPU 0% 利用率
   - **解决方案**: `--num-workers 8`（提升到 42%）

2. **训练不稳定**: Phase 1 Graph 模型需要禁用 AMP
   - **解决方案**: Phase 2 Enhanced Graph 修复了 dtype 问题

3. **数据库锁**: 多进程读取可能导致 `.db.lock` 文件残留
   - **解决方案**: 删除 `data/db/mp_materials.db.lock`

### 8.3 数据质量

1. **弹性异常值**: ~5-10% 弹性数据不满足物理约束
   - **建议**: 训练前过滤 `K≤0`, `G≤0`, `ν∉[-1,0.5]`

2. **化学体系长尾**: Top 化学体系仅占 1%
   - **建议**: 使用分层采样或化学体系加权
