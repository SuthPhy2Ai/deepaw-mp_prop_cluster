# Stage A 多任务学习为何在部分任务上胜过 zero：物理关联分析报告

## 结论摘要

当前结果不能简单解读为“zero 更强，Stage A 只是残留优势”。更准确的结论是：

- `Stage A` 胜出的任务，几乎全部属于一个**高覆盖、强耦合、同源电子结构子系统**：
  - `band_gap`
  - `cbm`
  - `vbm`
  - `efermi`
  - `is_metal`
- 这些任务不是彼此独立的标量，而是由**同一套能带结构、费米能级位置、占据关系**共同决定。
- 因而 `Stage A` 的多任务共享表征，很可能学习到了一个更稳定的“电子结构流形”，这使它在这些任务上略优于完全拆开的 `zero`。
- 相反，`zero` 胜出的任务主要是热力学标量：
  - `energy_per_atom`
  - `formation_energy_per_atom`
  - `energy_above_hull`
- 这说明这类任务更适合专门化拟合，而不一定需要依赖电子任务的共享约束。

一句话概括：

**Stage A 赢的不是“单个任务”，而是一整个物理上强相关的电子结构任务簇。**

## 2. Stage A 本身的任务组合为什么特别关键

`Stage A` baseline 实际启用的任务是：

- `energy_per_atom`
- `formation_energy_per_atom`
- `energy_above_hull`
- `band_gap`
- `cbm`
- `vbm`
- `efermi`
- `is_metal`

这 8 个任务的特点是：

- 覆盖率都很高，基本都在同一个高覆盖样本池上学习。
- 其中 5 个任务直接属于电子结构家族：`band_gap / cbm / vbm / efermi / is_metal`。
- 其余 3 个热力学任务与电子结构并非完全独立，也都和成键强弱、稳定性边界、轨道占据有间接联系。

换句话说，`Stage A` 不是“随便挑了 8 个任务一起学”，而是恰好组成了一个**统计覆盖高、物理耦合强、噪声相对一致**的任务包。

这对多任务学习非常重要，因为多任务共享是否有利，关键不在“任务数量多不多”，而在“这些任务是否共享同一潜在物理表征”。

## 3. 电子结构任务簇存在强物理耦合，而不是表面相关

下面这组训练集标签相关性很关键。它们不是模型输出相关，而是数据本身的目标相关。

### 3.1 电子能级三元组高度相关

在有共同标签的样本上，训练集相关系数为：

| Pair | Shared Samples | Corr |
|---|---:|---:|
| `vbm` vs `efermi` | 71,528 | 0.9396 |
| `cbm` vs `efermi` | 71,528 | 0.7786 |
| `cbm` vs `vbm` | 71,574 | 0.7708 |

这说明：

- `vbm`、`cbm`、`efermi` 几乎就是同一个电子结构坐标系上的不同投影。
- 如果模型学好了价带顶与导带底的相对位置，费米能级位置往往就不再是一个独立任务。
- 因而共享 backbone 在这三个任务上能得到额外监督，相当于用多个观测共同拟合同一个潜变量。

从物理上看，这完全合理：

- `vbm` 决定最高占据态位置。
- `cbm` 决定最低未占据态位置。
- `band_gap = cbm - vbm`。
- `efermi` 则对应占据分布平衡点，通常落在或接近由带边结构决定的位置。

所以这几个任务之间不是“机器学习上的巧合相关”，而是**由能带结构定义直接绑定**。

### 3.2 band gap 与金属性是近乎规则级关系

训练集上，按 `is_metal` 分组后的 `band_gap` 平均值为：

| Task | Metal Mean | Nonmetal Mean | Delta(nonmetal-metal) |
|---|---:|---:|---:|
| `band_gap` | 0.0000 | 2.0042 | +2.0042 |

这几乎就是教科书级别的关系：

- 金属通常带隙近零。
- 非金属通常存在有限带隙。

因此 `is_metal` 并不是一个与 `band_gap` 无关的独立标签；它更像是对同一电子结构几何形状的一个离散判别。

这解释了为什么 `Stage A` 在：

- `band_gap`
- `is_metal`
- `cbm`
- `vbm`
- `efermi`

上形成联动领先。

模型在多任务训练中会被迫学到：

- 带边在哪里
- 带隙是否闭合
- 费米能级落在什么位置
- 最终是不是金属

这些监督信号是相互校正的。

## 4. 为什么多任务共享会帮助 Stage A，而不是拖后腿

### 4.1 Stage A 的任务覆盖率非常整齐

训练集标签覆盖大致如下：

| Task | Train Label Count |
|---|---:|
| `energy_per_atom` | 123,902 |
| `formation_energy_per_atom` | 123,902 |
| `energy_above_hull` | 123,902 |
| `band_gap` | 123,902 |
| `efermi` | 123,856 |
| `is_metal` | 123,902 |
| `cbm` | 71,574 |
| `vbm` | 71,574 |

这意味着：

- 主干网络几乎在整个训练过程中都被高覆盖任务稳定更新。
- `cbm/vbm` 虽然覆盖略低，但仍有 7 万级样本，并非真正稀疏任务。
- 因此 Stage A 的共享 backbone 学到的是一个稳定的、密集监督的电子结构表征，而不是被稀疏任务噪声拉扯的 backbone。

### 4.2 Stage A 没有被弹性任务和结构大尺度任务污染梯度

`Stage A` baseline 不包含：

- 弹性任务：`bulk_modulus_vrh / shear_modulus_vrh / homogeneous_poisson / universal_anisotropy`
- 结构大尺度任务：`volume / density`
- 也没有把 `is_stable` 放进 baseline 里

这点非常关键。

因为这些新增任务往往带来：

- 更不均匀的标签覆盖
- 更大的数值尺度差异
- 更高的异质性
- 更弱的同源物理约束

所以 `Stage A` 的成功，不只是“多任务学习有用”，而是：

**它恰好做了一次“干净的多任务学习”**。

它共享的是一组相容任务，而不是一锅杂烩。

## 5. 为什么 zero 在热力学任务上反而更强

`zero` 胜过 `Stage A` 的主要任务是：

- `energy_per_atom`
- `formation_energy_per_atom`
- `energy_above_hull`

这些任务更像是**连续标量回归**，而且对误差极其敏感。

从物理和学习角度看，zero 的优势来源可能是：

### 5.1 热力学标量更适合专门化拟合

这几个任务虽然也与电子结构相关，但它们最终是非常精细的能量标量：

- `energy_per_atom` 关心总能量密度水平
- `formation_energy_per_atom` 关心相对于元素基准态的化学稳定性
- `energy_above_hull` 关心相图凸包上的相对稳定边界

这些量对：

- 成键环境
- 组成
- 局域结构畸变
- 参考能量基线

的细小变化都很敏感。

完全独立训练时，模型容量和优化过程可以全部服务于单一标量目标，不需要与带边位置、金属性分类共同妥协。

### 5.2 shared backbone 会把“电子结构一致性”当成正则，但这不一定总利于最小化能量误差

对电子结构任务来说，这种共享是一种好约束。
但对精细能量回归来说，它也可能是一种额外偏置：

- 主干被迫优先表示对 `band_gap/is_metal/cbm/vbm/efermi` 有利的特征方向。
- 而能量任务最优的细粒度方向未必完全一致。

因此，`zero` 的收益可以理解为：

**把热力学任务从电子结构多任务的共享偏置中解耦出来。**

## 6. 物理上如何理解 Stage A 的“互相引领风骚”

如果用物理语言来归纳，当前不是某个单一训练范式全面制胜，而是两类物理问题各自偏好不同训练方式：

### 6.1 Stage A 擅长的，是“同一电子结构流形上的多观测联合约束”

对应任务：

- `band_gap`
- `cbm`
- `vbm`
- `efermi`
- `is_metal`

这些任务共同描述的是：

- 电子能带边界在哪里
- 带隙是否闭合
- 占据边界如何放置
- 最终材料是金属还是非金属

这是一个天然适合多任务共享的物理簇。

### 6.2 zero 擅长的，是“单一标量精细回归上限”

对应任务：

- `energy_per_atom`
- `formation_energy_per_atom`
- `energy_above_hull`
- `is_stable`
- `volume`
- `density`

其中：

- `energy_*` 更像是能量基线和稳定性边界的精细回归。
- `volume/density` 是结构尺度量，本来就与电子带边簇不是同一学习子问题。
- `is_stable` 与 `energy_above_hull` 也有近似派生关系，更适合单线优化。

所以“Stage A 和 zero 互相引领风骚”这句话，本质上是在说：

**电子结构流形适合共享，多任务有利；单标量精细回归适合拆开，单任务有利。**

## 7. 对后续建模路线的启发

从这份结果看，最值得继续做的不是简单二选一，而是**按物理任务簇分层建模**。

### 路线 A：电子结构簇共享 backbone

建议把以下任务作为一个共享簇：

- `band_gap`
- `cbm`
- `vbm`
- `efermi`
- `is_metal`

必要时可加：

- `energy_per_atom`
- `formation_energy_per_atom`

但它们更适合作为弱耦合辅助头，而不是与电子簇完全同权绑定。

### 路线 B：热力学/稳定性簇单独建模

建议独立建模或单独家族建模：

- `energy_per_atom`
- `formation_energy_per_atom`
- `energy_above_hull`
- `is_stable`

原因是它们共享的是热力学稳定性信息，而不是纯电子带边几何。

### 路线 C：弹性任务继续独立家族

弹性任务目前显示出：

- 覆盖低
- 数值分布更难
- 与高覆盖电子任务不完全同源

因此继续采用 `v4/zero` 风格的独立或半独立建模，仍然更合理。

## 8. 最终判断

最终判断可以写得很明确：

- `Stage A` 在部分任务上胜过 `zero`，不是偶然，也不是因为 zero 不够强。
- 它反映的是**多任务学习在强物理耦合任务簇上的真实优势**。
- 尤其是在 `band_gap/cbm/vbm/efermi/is_metal` 这一电子结构簇上，Stage A 通过共享 backbone 学到了比完全拆开的 zero 更稳定、更一致的电子结构表示。
- `zero` 的优势则主要体现在热力学标量和独立任务上限探索上。
- 因而最合理的下一代方案，不应是继续追求“一个模型吃掉全部任务”，而应是：
  - **按物理关联分簇**
  - **簇内共享**
  - **簇间解耦**

这比单纯在 `Stage A` 和 `zero` 之间二选一，更符合当前实验事实，也更符合材料物性的物理结构。
