## 🔴 问题发现

**时间**: 22:43
**问题**: EXP-02 在数据加载完成后，训练开始时立即崩溃

**错误信息**:
```
RuntimeError: index_add_(): self (Float) and source (Half) must have the same scalar type
```

**根本原因**:
- AMP (自动混合精度训练) 将 `messages` 转换为 Float16
- 但 `agg` 张量使用 `torch.zeros_like(node_emb)` 创建，保持为 Float32
- `index_add_()` 操作要求两个张量类型一致

---

## ✅ 问题修复

**修复时间**: 22:44
**修复位置**: `src/mp_data_pipeline/models/backbones.py:80`

**修复前**:
```python
agg = torch.zeros_like(node_emb)
agg.index_add_(0, dst, messages)
```

**修复后**:
```python
# Fix AMP type mismatch: ensure agg has same dtype as messages
agg = torch.zeros_like(node_emb, dtype=messages.dtype)
agg.index_add_(0, dst, messages)
```

**说明**: 创建 `agg` 时显式指定使用 `messages` 的数据类型，确保类型一致。
